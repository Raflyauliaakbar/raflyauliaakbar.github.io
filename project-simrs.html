SIMRS & Monitoring Aset Medis RSU Syifa Medika

Sistem informasi berbasis web yang dikembangkan selama kegiatan Praktik Kerja Lapangan (PKL) di RSU Syifa Medika Banjarbaru[cite: 89]. Sistem ini dirancang untuk mengintegrasikan pelaporan kerusakan fasilitas & AC secara insidental, manajemen pemeliharaan rutin, kalibrasi alat medis, pemantauan parameter air bersih secara berkala[cite: 103], serta pengelolaan inventaris suku cadang dan tabung oksigen secara terpusat untuk mendukung efisiensi operasional rumah sakit[cite: 114].

Key Features

  • Manajemen hak akses bertingkat untuk 7 aktor operasional (Pelapor, Teknisi Umum/AC/Elektromedis, Petugas Inventaris, Kepala Teknisi, dan Direktur)[cite: 103].
  • Otomatisasi pemotongan stok suku cadang dan logistik tabung oksigen secara *real-time* berdasarkan input pengerjaan teknisi[cite: 127].
  • Pencatatan logbook pemantauan kualitas air bersih secara periodik berkala setiap 4 jam[cite: 111].
  • Fitur cetak laporan formal berbasis format dokumen PDF untuk evaluasi kinerja bulanan dan tahunan oleh jajaran direksi[cite: 150].
